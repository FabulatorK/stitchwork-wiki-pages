B2 查找任意精灵图

入门级创作者阅读约 11 分钟
适用于 Stitchwork 0.9.0 · 更新于: 2026-10-19

精灵图 · 面向创作者
我该怎么找到想替换资源的名字？
答案不是猜：图形标签页会直接从游戏里读出真正的名称。

你将学会：为屏幕上的任何美术找到准确的集合 / 材质 / 精灵图名称，分辨它属于两套精灵图系统中的哪一套，以及把还没加载的资源找出来。

开始之前：建议先阅读 B1，熟悉一下导出、编辑这一整套流程。本页只是把同样的方法扩展到任何图像资源，而不仅仅是大黄蜂的待机动画。

资源路径就是身份证——来自游戏本身

一个替换资源能否生效，只取决于它的文件路径是否与资源身份一致：Sprites/Collection/Material/Sprite.png。这三个名称不是你自己起的，而是游戏内部真正使用的资源标识。只要有一个字母写错，游戏就找不到你的文件。因此，这项技能的核心其实只有一句话：从游戏里读取真正的名称。 图形标签页就是为此而设计的，而且读取的是实时数据。

为什么有两个浏览器？因为游戏有两套图像系统

图形标签页为每一种渲染管线分别提供了一个浏览器（关于原因可参阅 Stitchwork 工作原理）。在资源库面板顶部的模式行里选择：

  • 动画——tk2d。几乎所有动画角色、敌人和 Boss 都在这里。
  • T2D 贴图——Texture2D。普通贴图和 UI 图标，例如菜单、HUD、特效、游戏内道具，以及部分技能和过场动画资源。由 Unity 自带的 Animator 逐帧播放的 T2D 美术也在这里。

如果不知道某个资源属于哪一种系统，就两个都查一遍。能够找到它的那个浏览器，就是它真正所属的系统。通过简单排查能自主解决绝大多数“为什么替换没有生效”的问题。

指向它——场景内选取

在游戏里的任何地方按 P，不管有没有打开面板，都会进入选取模式；再按一次 P 即可取消。想换一个按键，就按 0 打开设置 › 快捷键，找到场景内选取。你也可以从图形标签页开始（按 3，或点击屏幕顶部边缘的图形标签页）。还没选中任何东西时，资源库面板上的大按钮是游戏场景内选取对象（动画模式）或场景内选取贴图（T2D 贴图模式）；选中之后，已选取那一行里的小按钮选取作用相同。选取模式会隐藏各个面板、顶部标签页、资源包面板和设置窗口，直到选取结束（资源包面板会保留你还没应用的更改），并把游戏画面本身变成一个资源浏览器：

  • 已开启类别中的每个对象都会套上细细的边框，并根据类型显示不同颜色：青绿色是 tk2d（动画和静态对象都算，HUD 组件也包括在内），蓝色是 T2D，橙色是粒子系统，紫色是网格。整个场景看起来就像一张标满注释的蓝图。
  • 屏幕顶部的标签按钮可以控制显示哪些类别：“tk2d 动画”、“T2D 贴图”、“粒子”和“网格”。每个标签按钮都会显示数量。从哪里进入，决定了哪些标签按钮开启：从动画模式进入，只开启“tk2d 动画”；从 T2D 贴图模式进入，只开启“T2D 贴图”；按 P 进入，两个都开启。进入时粒子和网格总是关闭的。需要的时候再把它们打开。场景里的粒子渲染器比其他任何东西都多得多，一直开着的话，你要找的对象就会被淹没。开启“T2D 贴图”时，第二排标签按钮会按照景深层级筛选世界资源（前景 / 主层 / 背景），这是快速定位背景图层、排除前景遮挡的最好方法。暗角、雾层之类的全屏遮罩不画边框，也永远不会被自动选中。在某个位置滚动滚轮时，它们排在最后，所以不用标签按钮也能选到。
  • 选取规则：默认优先选择鼠标下最小的包围框（通常也是最具体的对象）。如果想选一张很大的图片，请尽量点击它的中央区域。使用鼠标滚轮可以在重叠对象之间循环切换。绳索、锁链这类细长的美术，可点击范围至少有 8 像素宽，所以也能点中。对象旁边的信息卡会显示预览图、名称、类别标记和原始名称。如果是 T2D，类别标记还会加上景深层级，例如“T2D 贴图 · 背景”。边框重叠时，信息卡会显示“此处第 2/5 个 · 滚动查看后面的对象”。如果目标和屏幕一样高（比如背景图），信息卡会跟着鼠标指针走。屏幕顶部的提示条会再列一遍操作方法：单击选取，“滚轮切换重叠层”，右键单击或按 P 取消。

点击后会打开什么

鼠标左键点击即可直接跳转到对应位置：

选取的对象打开的内容
tk2d 动画对象动画模式，列出这个对象的动画片段，并显示它当前播放的那段动画。
T2D 或 UI 对象T2D 贴图，并自动选中对应图集与精灵图。
静态 tk2d（例如灵丝球的边框这类 HUD 组件、没有动画器的场景物件）对应的精灵文件，立即进入编辑状态，可直接热重载。选取会跳过列表。
粒子系统选取会选中整个粒子系统：T2D 贴图会打开这个粒子材质使用的贴图。如果这张贴图没有精灵图，编辑（从原版新建）会把整张贴图写到 Spritesheets/T2D/<name>.png 并打开。
网格和粒子选取一样，在 T2D 贴图中打开这个网格的贴图。网格指普通网格渲染器绘制的美术：垂挂的布料、帷幔、绳索和锁链；圆顶状的神龛美术，比如钟心镇钟居上装的那口钟、编织者神龛的头部和潜钟；还有草。
雾气、蛛网、上升气流、雨和闪光（在遮罩后面滚动的美术）那张滚动贴图，例如 web_mist_tiled 或 dust_mist_texture_solid，而不是白色的遮罩精灵图。
空白处提示条会显示“此处没有可选取的对象”。
T2D 贴图找不到的对象提示“… 不在本场景的列表中。请在该特效存在时暂停游戏，再进行选取。”

鼠标右键点击（或任意 Stitchwork 快捷键）取消选取模式；Esc 归游戏的暂停菜单使用。

Ctrl+单击会让镜头跟随这个对象，而不是选中它。选取模式不会关闭，所以你可以接着 Ctrl+单击另一个目标。右上角会出现一块镜头提示牌，上面的解除会把镜头还给大黄蜂。

粒子选取时，屏幕上必须有正在显示的粒子（空闲的发射器没有东西可瞄准），而一闪而过的爆发特效很难实时点中。推荐的做法是：趁特效还在半空中，用配套模组的全局时间暂停把时间冻结（配套模组），然后慢慢选。

tk2d——动画模式

  1. 动画。资源库会列出场景载入以来游戏播放过动画的每个对象，名称都是对应的 GameObject 名称——例如大黄蜂就是固定排在最上方的 Hero_Hornet(Clone)。静态 tk2d 对象永远不会出现在这个列表里：请改用场景内选取。
  2. 点击一个对象 → 资源库会切换到它的动画片段。点击一个片段：对象会播放它，并停在第一帧。
  3. 在预览播放面板的帧条上选一帧，或者用上一帧 / 下一帧切换 → 控制台的身份卡会在一行里写出你需要的三个名称：集合 › 材质（图集）› 精灵图。
  4. 控制台此精灵图分组里的编辑（从原版新建）会导出这一帧、复制到你的工作区文件夹，并自动打开图片——这就是你的起始画布。整段动画分组里的预备 N 个待编辑的精灵图则会一次处理整段动画（仅导出不同的精灵图，不重复）。动画控制台会逐一介绍每个控件。

这些名称是读取出来的，不是记出来的。对于你的游戏版本来说，身份卡永远是正确答案；教程里的名称只能保证在它编写时是正确的。（Knight 的例子见 B1；更多容易混淆的内部名称请参阅术语表。）

Texture2D——T2D 贴图模式

  1. T2D 贴图。资源库会列出内存中的 T2D 贴图，列表上方有搜索材质贴图。每一行显示名称和尺寸。独立贴图（不属于任何打包图集的贴图）排在最后，位于“独立贴图”标题下。
  2. 点击一张贴图 → 它的精灵图会列在下方，标题为“精灵图（n）”，并带有筛选精灵图。预览播放面板会显示读数（W×H · n sprites）、在选中精灵图上画框的图集视图，以及精灵图视图。
  3. 如果某一行带有绿色的 S 标记，表示已经载入了整图替换（提示文字为“图集替换”）；蓝色数字标记则统计被单独替换的精灵图数量（提示文字为“已加载的独立精灵图”）。无论哪一种，都说明你的资源包已经成功命中了对应资源，这是确认替换是否生效的快捷方法。
  4. 想编辑的话，选中一张精灵图，然后点击精灵图列表上方的编辑（从原版新建），或者那一行上的小按钮编辑。Stitchwork 会把原版精灵图写到你工作区文件夹里的 Sprites/T2D/<atlas>/<sprite>.png（独立贴图则放到 Sprites/T2D/_standalone/），然后打开它，可以立即开始绘制。文件一旦存在，按钮就会变成编辑（打开已有文件）。
  5. 在预览播放面板的导出下面，有图集（整张图）、全部精灵图和精灵图（只导出选中的那一张——通常就是场景内选取之后最常用的操作）。它们只会把原版参考图写进 Dumps/，并用一行状态文字报告结果。导出永远不会覆盖文件：第二次点击图集或精灵图时，会显示“… 已导出。无新文件操作。”全部精灵图找不到新的精灵图可导出时，也会告诉你。

让透明图片更容易看清：预览播放面板的视图下方有一行背景板，两种模式共用。切换按钮可以在黑色与白色背景之间切换，并通过滑块控件调整背景透明度。亮色资源适合黑底，暗色或大量发光效果则通常在白底下更容易观察。

关于图集名称。T2D 贴图显示的是图集的通俗名（Hornet，而不是原始名称 sactx-0-2048x2048-BC7-Hornet-abc123）：它显示什么，你的路径里就写什么（B4 › 通俗名）。

“刚才到底触发了什么？”——T2D 日志

T2D 日志是资源库模式行里的第三个模式。它的标题是“T2D 触发日志”，旁边有清除按钮。T2D 贴图显示的是当前内存中的资源；而 T2D 日志记录的是游戏引用过的资源。因此，一些只会短暂出现的资源，例如闪电特效、攻击特效、梦境画面，都会在它们出现的瞬间被记录下来。只有资源库正在显示 T2D 贴图或 T2D 日志时，它才会记录，每个图集占一行。最新的 20 行会一直保留，更早的行会在 8 秒内渐渐淡出。触发一次对应效果，从日志里读出它的图集，然后左键点击条目，即可直接跳转到 T2D 贴图中的对应位置。这是寻找那些只存在几帧画面的资源最快的方法。

没有加载，就找不到

两个浏览器都只能显示当前已经加载到内存中的资源。因此，还没遇到的 Boss、还没进入的区域，以及还没获得的物品，它们对应的图片尚且不存在于内存里，再怎么搜索也不会出现。对此，唯一的解决办法是身临其境。进入对应区域、开始战斗、打开菜单……相关资源加载之后，再进行搜索。

如果想一次性导出所有资源，可以使用全量导出：实用工具（按 7，或点击实用工具顶部标签页）→ 资源导出面板 → 全量导出。它有一个需要点击两次的保险机制：第一次点击只会让它进入待命状态（“点击开始”），因为它会依次进入游戏中的所有场景逐一进行资源提取，并结束当前游戏流程。只有开启了载入场景时导出精灵图，这个按钮才能用：全量导出其实就是这项导出，只是由 Stitchwork 带着它走遍每一个场景。屏幕底部正中的进度框会实时显示场景数量（“场景 n/N”）与耗时（分钟）；按住 Backspace 可以取消，进度会保存下来。某些场景停留较久属于正常现象。请先读取存档：在标题画面，这个按钮会保持禁用。全量导出永远不会写入你的存档：从开始导出到回到标题画面，Stitchwork 会拦下所有存档、自动存档和成就。建议尽早执行一次——更多细节请参阅资源导出，包括一个重要保证：即使启用了资源包，导出的内容依然始终来自原版游戏。

同名图集

偶尔，一个 T2D 通俗名会对应不止一个图集页（比如两个 Hornet 页）。T2D 贴图会用后缀区分它们——Hornet-0、Hornet-1——但你的路径里仍然只写通俗名本身。单张精灵图文件（Sprites/T2D/Hornet/<sprite>.png）不需要任何额外处理：一张精灵图只会放到含有它的那一页上。只命名为 Hornet.png 的整图文件，分不清两个尺寸相同的页；想指定其中一页，就在文件名里保留页码，写成原始的 sactx-1-… 形式（T2D 精灵图）。

tk2d 那边也有类似的问题——两个集合共用同一个名称——见精灵图路径速查里的路径 #5。

常见问题

  • “找不到某张精灵图。”最常见的原因是它没有在当前场景中载入。进入那张精灵图出现的场景，再找一次。
  • “名字是一串 sactx-0-… 的乱码。”那是 Unity 原始图集名称。请使用 T2D 贴图显示的通俗名。
  • “导出来是空白图片。”那个位置本来就是空槽位，游戏自带不少这样的空图。你真正需要的是旁边那张精灵图。
  • 名称最后带 Cln（例如 Conductor Cln、Tools Cln、Dock Flyer Cln）。这只是 Team Cherry 在游戏中可能用于表示 Clean 或 Collection 资源的内部标签，没有任何特殊含义。不过在路径中请原样保留整个名称，包括 Cln 后缀。
  • Dumps/ 只是导出目录，其中内容供文件夹结构参考。Stitchwork 从不从这里读取资源。如果想让修改后的帧真正生效，需要把它复制到 Sprites/ 或者你的资源包里。每张精灵图旁边的编辑按钮已经自动完成了这一步；而全量导出留在 Dumps/ 里的文件，只会静静待在那里，直到你手动移动它们。
  • 总览面板里的计数行（“tk2d 精灵图：… · T2D：已加载 … · 图集：…”）统计的是你已经生效的替换，而不是内存里的游戏美术。
  • DebugMod 的面板开着。这时 Stitchwork 会取消选取模式、关闭自己的面板，它的按键也什么都打不开（会弹出一条提示说明这一点）；先用 DebugMod 的切换键隐藏它的面板，再重新选取。
