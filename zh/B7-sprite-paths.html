B7 精灵图路径速查

参考创作者阅读约 5 分钟
适用于 Stitchwork 0.9.1 · 更新于: 2026-10-22

精灵图 · 参考
精灵图文件可以放的每一个位置，以及每个位置的用途。
做资源包的时候，随手把这一页开着。

你将学会：回答两个问题，就能给任何一张精灵图替换选定准确的路径；六种布局也能一眼认出来。

两个问题选定路径

  1. tk2d 还是 T2D？这是游戏的两套精灵图系统。会动的角色和敌人几乎都是 tk2d；HUD、菜单、特效和部分技能美术通常是 T2D（Texture2D），不过也有一些 HUD 边框（比如丝之核的边框）是 tk2d。图形标签页会告诉你答案（B2）：出现在动画模式里的精灵图是 tk2d，出现在 T2D 贴图里的是 T2D，场景内选取的信息卡也会写明它属于哪一类。
  2. 新画的美术，还是移植现成的整图？创作任何新内容 → 单张（所有新作品都推荐走这条路）。把 CKC 的输出或旧作品里已经完成的整图搬进来 → 整图（B3，移植用的路线）。
单张整图
tk2dSprites/{Coll}/{Mat}/{Sprite}.pngSpritesheets/{Coll}/{Mat}.png
T2DSprites/T2D/{Atlas}/{Sprite}.pngSpritesheets/T2D/{Atlas}.png

另外还有两种进阶路径：一种用来处理重名，一种用来给某一段动画配专属美术（都在下文）。

本页的每条路径，都从资源包的 Stitchwork/ 文件夹开始；对你的工作区文件夹来说，则从 <Game folder>/Stitchwork/ 开始（见资源包目录结构）。

六种路径

1 · 单张 tk2d 精灵图——最常见的情况

Sprites/{CollectionName}/{MaterialName}/{SpriteName}.png

动画角色、敌人或 UI 元素的一帧。举个例子，大黄蜂待机动画的一帧（别忘了，游戏把她叫作 Knight）：

Sprites/Knight/atlas2/idle0000.png

Knight 是集合，atlas2 是材质（也就是那张图集），idle0000 是精灵图。这三个名字都可以从动画控制台的身份卡上直接读出来（B2）。完整的操作步骤见 B1。替换图可以比原版大——见下文的锚点。

2 · tk2d 整图

Spritesheets/{CollectionName}/{MaterialName}.png

把一整张图集做成一个 PNG，布局必须和原图完全一致，尺寸是原尺寸或原尺寸的等比缩放（因为它会顶替原图的位置）。它用来移植 CKC 的输出和旧式整图皮肤，不用来创作新美术 → B3。

Spritesheets/Knight/atlas2.png

3 · 单张 T2D 精灵图

Sprites/T2D/{AtlasName}/{SpriteName}.png

Texture2D 系统里的一张精灵图（HUD、UI、特效）。{AtlasName} 是通俗名（去掉了 sactx-… 前缀和哈希值）。→ B4。

Sprites/T2D/Hornet/health_pip.png

扁平的写法 Sprites/T2D/{SpriteName}.png（没有图集文件夹）也能载入。它会在所有图集里匹配这个精灵图名，所以两个图集有同名精灵图时，请用 #3（B4 › 扁平文件）。正是因为这个原因，资源包体检报告会给扁平文件附上一条提示信息。

4 · T2D 整图

Spritesheets/T2D/{AtlasName}.png

原位替换一整张 T2D 图集，宽和高都必须和原图完全一致（比 #2 更严格，#2 允许等比缩放）。在 T2D 贴图里点导出 › 图集，就能得到这张图集的参考图。→ B4。

5 · 实例专用的 tk2d 精灵图——进阶

Sprites/{CollectionName}/{VanillaTextureName}/{SpriteName}.png
Spritesheets/{CollectionName}/{VanillaTextureName}.png

专门用来处理一种少见的冲突：两个集合名字相同，装的却是不同的美术。路径 #1 会作用于所有同名的集合，通常这正是你想要的。只有两者需要不同的美术时，才用这条路径。如果你拿不准自己需不需要它，那就是不需要。

怎么知道需要它。Stitchwork 会告诉你。当你为两个集合共用的名字提供了文件，并且两份副本都已载入时，日志会第一次打印这条警告：

[SpriteLoader] Duplicate collection name '{CollectionName}' (instanceId …,
N definitions, dataGuid '…'). Use the vanilla texture name as the folder/file name
to target this instance specifically: …

后面几行会列出触发这条警告的那份副本里，每个材质的原版贴图名称。原始贴图名称通常每份副本都不一样，所以它就放在平常放材质文件夹的位置。日志只会列出触发警告的那份副本的名称；另一份副本的贴图名称，需要借助外部的资源工具才能查到。比如日志给你想要的那份副本列出的名字是 prisoner_b：

Sprites/{CollectionName}/prisoner_b/idle0000.png

它可以和 #1 搭配使用。查找时先找实例专用路径，再找材质路径。所以两种文件可以一起放：用材质路径的文件作为所有副本的默认，再给不一样的那一份副本放一个实例专用的文件。

如果贴图名称也相同，这条路径同样分不清这两份副本，一个文件会同时作用于两者。名为 Slab Prisoner 的敌人和同名的 NPC 就是这样一对：两者都是 Slab Prisoner Cln，都用 atlas0。单张精灵图文件仍然会作用到正确的那一个，因为两者没有同名的精灵图。整图只会落在图集形状和它吻合的那份副本上；另一份会拒绝它，日志里也会写明。

6 · 单段动画专属的 tk2d 精灵图（贴布绣）——进阶

Sprites/{CollectionName}/Clips/{ClipName}/{SpriteName}.png

把替换限定在某一个指定名称的动画片段上——其他复用同一张精灵图的动画，仍然使用共享的替换图（或原版）。注意，这一层文件夹是集合，而不是材质（一段动画的帧可能分布在好几页图集上）。文件夹名就是动画在运行时的名称（不区分大小写），它会作用于所有已载入的同名动画。它只在这段动画上覆盖路径 #1。详见帧复用：一图多动画。

带锚点和精确定位的写法

任何单张 tk2d 路径（#1、#5 的 Sprites/ 写法、#6）都可以在文件名上带一个锚点标签，只在你的替换图比原版的槽位更大时才用得上。T2D 文件（#3）不带锚点，它们用的是尺寸标签（T2D 精灵图）。

Sprites/{Coll}/{Mat}/{Sprite}@t.png        ← top   (@b/@l/@r/@c too; untagged = bottom)
Sprites/{Coll}/{Mat}/{Sprite}@p120_64.png  ← precise pivot (px from left, py from bottom)

完整规则——什么时候生效、五种预设、精确的 @p 写法——见更大的画幅：锚点。整图文件（#2、#4，以及 #5 的 Spritesheets/ 写法）不带锚点：整图保持原来的布局，所以单张精灵图得到的空间不能超过它的位置。

约定

  • 整图和单张文件一起用时。在同一个资源包里，单张精灵图文件会画在这个包自己的整图上面。更靠上的资源包里的整图，会盖住它下面所有资源包的单张文件，也会盖住你工作区文件夹里的单张文件（tk2d 以材质为单位，T2D 以图集页为单位）。路径 #6 的 Clips/ 文件也遵循同样的规则。
  • 不区分大小写，但最好和导出的文件一致。Knight/atlas2/Idle0000.png 和 knight/atlas2/idle0000.png 都能载入。请使用导出文件的大小写。顶层文件夹（Sprites、Spritesheets……）是例外：在 Linux 和 Steam Deck 上，大小写写错的顶层文件夹会被忽略（资源包目录结构）。
  • Stitchwork 会忽略对不上的文件。它会忽略隐藏文件（以 . 开头）、系统文件（.DS_Store、Thumbs.db）和源文件（.psd、.kra），所以你可以把分层的源文件放在导出的 PNG 旁边。名字打错的文件也会被忽略：替换没有显示时，请检查文件名。

其他资源类型

这一页只讲精灵图。其他资源类型见：音频 → Sounds/{ClipName}.{ext}（D1）· 视频 → Videos/{CinematicName}.{ext}（E1）· 文本 → Text/{Sheet}/{LANG}.yml（C1）· 字体 → Fonts/_fallback/{name}.ttf 等（C2）· 颜色规则 → Recolor/{SceneName}.txt（B9）。
