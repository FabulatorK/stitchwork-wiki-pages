B9 色彩

常规级创作者阅读约 9 分钟
适用于 Stitchwork 0.9.0 · 更新于: 2026-10-19

精灵图 · 面向创作者
无需绘制精灵图，就能给场景、大黄蜂或攻击特效等元素重新着色。
所见即所得，根据实际视觉效果调整，Stitchwork色彩工具会替你写好规则文件复现这些效果。

你将学会： 给场景里的道具和粒子重新着色，设置整个房间的光照，调整大黄蜂的饱和度和色相，给挥砍和毒特效重新着色，再把这些全部放进资源包发布。

色彩规则

色调是绘制对象时游戏通过着色器（滤镜）额外加上的颜色，和贴图里画好的颜色是两回事。

场景规则会把匹配到的色调替换成你选的颜色。它匹配的是颜色值，而不是资源的身份或区域主题：不同的对象可能共用同一种色调，美术却并不相同。想知道色彩规则具体能达到什么攻下，请看下面介绍的场景扫描和轮廓显示。

  • 规则仅对已有的图像内的颜色做修改。想重画美术素材本身需要替换精灵图（开始制作资源包）。
  • 场景规则作用于场景精灵图和粒子。角色用的着色器会忽略色调。不过有两个调节项能作用到角色：场景的环境光会作用到所有角色，大黄蜂（玩家角色）标签页只作用到大黄蜂。
  • 颜色规则的修改额外作用于游戏渲染，不修改本体文件。关掉资源包或删除规则，下次重新载入时原版颜色就会还原。

颜色模式

按 3 键（或点击屏幕顶部的图形标签页）打开 “图形”，然后在资源库面板顶部的模式里选择颜色。颜色模式会同时用到图形的两个面板：

  • 场景（左侧）：房间名称和它的规则文件、扫描，以及两个不写入任何内容的视图开关。
  • 资源库（右侧）：三个标签页，场景、大黄蜂（玩家角色）和特效。每个标签页都有一个可以重新着色的项目列表，列表下方是一个编辑器。

选中一行，改动它的数值，游戏画面会立刻跟着变：这是预览，还没有保存任何东西。编辑器底部的那行字会显示“预览中 · 未写入”。接下来：

  • 写入规则会保存它。那行字会变成“已写入”，后面跟着文件名。
  • 还原会重置预览，回到已有的规则，或者回到原版的渲染效果。
  • 删除规则会删掉已保存进文件的规则。以防误触，你需要重复点击一次（“点击移除”）确定。

每一行右侧用于陈列规则，显示文件里已经写了什么，所以你的规则改了哪些东西，一目了然。编辑器顶部的标记会显示规则写到哪里：本场景或所有场景；鼠标指向它，可以看到文件的完整路径。

场景颜色

场景标签页会列出房间里的色调，用得最多的排在最前。打开颜色模式时会自动扫描一次，切换场景时会再扫描一次；场景面板上的重新扫描可以手动再扫一遍。每一行显示颜色和数量：#5A7D6BFF ×42 表示有 42 个对象共用这种色调，所以针对它的规则会同时改掉这 42 个。纯白（#FFFFFFFF）会被特别标出：它是未着色的默认值。针对它的规则可能会影响到许多原本毫不相干的对象；写入之前，先看看数量和轮廓。场景面板上的“当前已重新着色”计数，可以让你快速确认规则到底有没有匹配到东西。

在编辑器里，用十六进制输入框或 R、G、B、A 滑块设置新颜色。作用范围决定规则写到哪里：本场景写入这个场景的文件；所有场景写入 _global.txt。选中的对象如果不属于这个场景，编辑器打开时作用范围就是所有场景。

在游戏场景中查找颜色

颜色查找是反过来查。点击房间里的一个对象，来源卡片会告诉你它是用哪种颜色绘制的，以及一条规则会波及多大范围（“本场景中另有 12 个对象也使用此项……”）。打开在游戏场景中描出它们的轮廓，就能看到所有共用这种颜色的对象。这里只能选中场景物件。它就是颜色模式下的场景内选取。

整个房间的光照：场景环境光

场景环境光是列表的第一行。它设置房间里所有东西都会受到的环境光，角色也包括在内。想让“这个房间有黄昏的感觉”，就调它。它只接受红、绿、蓝三个值。

大黄蜂

大黄蜂的着色器会忽略色调，但它会读取一个饱和度数值。游戏会为每个区域分别设置这个值，通常在 0.5 左右。所以你画的颜色和你在游戏里看到的颜色不太一样：游戏会把她调得比你的文件更鲜艳一点。大黄蜂（玩家角色）标签页为她的身体精灵图提供了三个调节项。其他角色和她的特效，都保持游戏自己的颜色。

调节项范围游戏的数值作用
饱和度-1 到 2按区域设置，通常为 0.5控制她有多鲜艳。为 0 时显示你文件里的颜色；更低则逐渐褪向灰色。
色相-1 到 10让她所有的颜色沿着色环转动。
明度0 到 21只提亮（大于 1）或压暗（小于 1）她身上有颜色的部分。白、灰、黑保持不变，所以面具依然是白色。大于 1 时，红色会偏向粉色。

每个调节项都有一个滑块和一个数值框。滑轨上的刻度标出中性值，下方有一个重置按钮（饱和度的是“游戏默认 · 重置”）。饱和度另外有一个你的美术素材原有颜色 · 0按钮。三个调节项合在一起，就是一套 HSV 调节：比如粉色的披风，就是较低的饱和度，加上大于 1 的明度。

明度需要专门的着色器。它要多绘制一遍。在 macOS 和 Linux 上，目前还没有测试过。如果编辑器显示不可用，旁边的说明会给出两个原因之一：DLL 旁边的 stitchwork.assetbundle 比你的 Stitchwork 旧（请从同一个发布版本安装这两个文件），或者你的图形 API 跑不了这一遍绘制。

灵丝档位：用她的颜色显示灵丝

大黄蜂（玩家角色）标签页顶部的灵丝档位开关，会让她的颜色显示她现在能释放几次灵丝技能：0、1 或 2+。这样你看她本人就知道，不用去看 HUD。

开关开启时，编辑器会多出一行档位。写入规则和删除规则只作用于你选中的档位。调节项旁边的圆点表示哪些档位已经有规则。基础是不分档位时她的颜色：游戏自己的，或者你设置的数值。没有单独规则的档位，会使用下面的默认值：

调节项放不了能放一次能放两次或更多
饱和度0.1基础基础 + 0.2（最大 2）
色相基础基础基础 + 0.05
明度基础基础基础

特效

特效标签页分成两个小组：

  • 挥砍：基础、火和毒，也就是你织针挥砍的颜色。基础色会在你下一次挥砍时生效。正在生效的附魔仍然显示它自己的颜色；在战斗中，这种颜色本身就传递着信息。
  • 毒：
    • 色调和玩家分别设置花芯囊给工具和大黄蜂染上的紫色。
    • 色相会偏移毒特效的色相，可以针对所有工具，也可以只针对某一个。
    • 工具按钮会依次切换“所有工具”，以及本次运行中游戏读取过毒特效色相的每个工具。
    • HUD 和物品栏会立刻更新。已经生成的工具要到下一次生成时才会改变。

查看你自己的颜色

场景面板上“视图 · 仅本次运行”下面有两个开关，它们只改变你看到的画面，不写入任何内容：

  • 关闭色彩曲线调整。很多场景会给整帧画面调色，大黄蜂也包括在内。这个开关会在本次运行中关掉调色。场景没有调色时，这个开关不可用。
  • 平衡检查会同时预览三样东西：大黄蜂的饱和度设为 0、关闭调色，以及白色的环境光。开启后，大黄蜂看起来就和你用看图软件打开的 PNG 一样。关掉它，各项数值都会恢复。如果你改动了大黄蜂的饱和度或环境光，它会先自动关闭。

想手写的话：规则文件

所有颜色规则都放在 Recolor/ 里，可以在资源包中，也可以在你的工作区文件夹里（<Game folder>/Stitchwork/Recolor/）。房间调好之后，推送会像其他资源一样，把这些文件放进你的资源包。你手动保存的规则文件，片刻后就会生效。Recolor/ 里的每个文件都是这样，无论是在工作区文件夹里，还是在已启用的资源包里。编辑器自己写入的内容则会立刻生效。

文件夹名是 Recolor/。旧版本用的是 Recolour/，资源包里的 Recolour/ Stitchwork 仍然能读取。Stitchwork 启动时会把你工作区文件夹里的它改名；资源包里的则要你自己改名，体检报告会标出这个旧名字。

场景规则：Recolor/<SceneName>.txt

场景名就是场景面板上显示的那个名字。每行一条规则；既没有 -> 也没有已知键的行，都算作注释。下面的颜色只是示例；你自己规则里的源颜色，要从场景扫描里取。

example tint adjustments for this room
#5A7D6B -> #4F7A8C
#A8C07A -> #9FB8D0 0.08
particle: #C8E6B4 -> #B4D2F0
ambient: #6E7B94
group: Foreground
  • #RRGGBB -> #RRGGBB 用来替换一种色调。两边都可以写成 #RRGGBBAA，带上 alpha。
  • 行末可选的数字是容差：一种色调要接近到什么程度才算匹配。默认值是 0.05，范围是 0.001 到 0.5。想让一组几乎相同的色调一起变，就把它调高。
  • 在前面加上 particle:，规则就会作用于粒子系统。
  • ambient: #RRGGBB 设置场景环境光。写入规则保存时会在末尾多加两位 alpha（#6F978DFF）。环境光会忽略 alpha。
  • group: <name part> 会把精灵图规则限定在场景中完整路径包含这段文字（不区分大小写）的对象上。写了几行 group: 时，对象的路径只要包含其中任意一段文字，就算匹配。所有来源的 group: 行会合并成每个场景的一份列表。这份列表会限制这个场景的所有精灵图规则；粒子规则不受它影响。

Recolor/_global.txt 存放作用于所有场景的规则。它只读取普通的 -> 规则（不读 particle:、ambient: 和 group:），而且它还能作用于跨场景存在的东西，比如 HUD 图标和常驻特效。

大黄蜂：Recolor/_hero.txt

saturation: 0.8
hue: -0.1
brightness: 1.2
tiers: on
saturation@casts0: 0
hue@casts2: 0.15
  • saturation、hue 和 brightness 的取值范围见上面的表格。超出范围的数值会被截到边界，逗号也可以当作小数点用。
  • tiers: on 或 tiers: off（也可以写 1 和 0）用来设置灵丝档位开关。
  • 在调节项名称后面加上 @casts0、@casts1 或 @casts2，就是只为一个档位设置这个调节项（2 表示两次或更多）。
  • 其他行都会被忽略，所以你可以在文件里写备注。

特效：Recolor/_slash.txt 和 Recolor/_poison.txt

  • _slash.txt 接受 base:、fire: 和 poison:，后面各跟一个颜色，例如 base: #FFD27F。
  • _poison.txt 接受带颜色的 tint: 和 herotint:；hueshift: 后面跟一个 -1 到 1 的数字，作用于所有工具；hueshift[Tool Name]: 只作用于一个工具。游戏第一次读取某个工具时，日志会打印出这个工具的名称和原版数值。

两个资源包意见不一时

资源包按优先级顺序读取，最先读到的资源包会拿下某个色调或某个键。和精灵图不同，在这里你的工作区文件夹优先于所有资源包，所以编辑器显示的永远是你刚写的内容；在工作区文件夹里写 tiers: off，也能关掉某个资源包的灵丝档位。

落败的规则会显示在资源包管理器的被覆盖里。落败的 ambient: 行显示为 <scene>/ambient。

文件两个来源
场景文件、_global.txt、_slash.txt两个来源设置的颜色一样，就不算冲突。
_hero.txt、_poison.txt同一个键只要有两个来源，即使数值相同，也算冲突。胜出的来源生效，每个落败的来源都会在被覆盖里多出一行。

完整说明见优先级与冲突。
