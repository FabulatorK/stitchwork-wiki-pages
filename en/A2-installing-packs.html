A2 Installing Packs

introplayercreator4 min read
For Stitchwork 0.9.0 · Last edited: 2026-10-20

Foundations · everyone.
Find a pack someone made, install it, and turn it on.

Already installed Stitchwork? Pick one installation method below, then enable the pack. Otherwise, start with A1 · setup.

Where packs live

Thunderstore is the main mod hosting platform. We recommend that creators upload their work there. It's free, and you don't need an account to download mods.
Community Discords and GitHub releases turn up the rest.
A few packs are on Bilibili and on Chinese cloud drive services. Some Chinese skin creators make a limited release there, to stop illegitimate ports of their work.

A listing worth trusting usually has:

  • screenshots or links to the showcase videos,
  • an author,
  • what it targets (sprites / audio / text / video),
  • a recent update date,
  • and a comprehensible README page.

Installing Packs — three ways

Mod manager (recommended). Several mod managers connect directly to Thunderstore. We recommend Cogfly (GitHub page). Download Cogfly directly. Gale and r2modman are valid alternatives. Search for the pack. Click Install. It pulls in dependencies (BepInEx, Stitchwork itself) for you — no folder wrangling. The pack lands in the profile's BepInEx\plugins\ folder. Leave it there: Stitchwork finds it. This is true for Customizer skins too.

The global Packs folder (recommended for manual installs). Stitchwork makes a Packs folder in the game folder on its first start. Extract the pack there:

<Game folder>\Packs\{packname}\Stitchwork\

Every mod-manager profile sees this folder, and a mod-manager update never touches it. The on/off state of each pack stays per profile. The Global folder button in the Pack Manager's PACKS header opens this folder, and makes it when it is missing. With no packs installed, the Pack Manager's list shows the folder's full path.

A different packs folder, or an install for one profile

To use a different folder, open Settings › Folders. To open Settings, press 0, or click the gear tab at the right end of the pull tabs. Type the path under Global packs folder, or click Browse…. Use the default sets <Game folder>\Packs\ again. The Pack Manager reads the packs from the new folder at once, and keeps the changes that you did not apply yet. This setting is in the config of the current mod-manager profile, so other profiles keep their own setting.

Manual, inside a profile. Extract the zip into BepInEx\plugins\, where Thunderstore installs land:

BepInEx\plugins\{author}-{packname}\Stitchwork\

In both manual layouts, the pack needs its Stitchwork\ (or Patchwork\) subfolder. Stitchwork does not find a pack that sits one level too high.
If a pack never shows up, this is the first thing to check.

Customizer skins — nothing to move. Skins made for Silksong Customizer show up as packs on their own. Stitchwork reads them in place and never changes their folders. It looks in two places:

  • BepInEx\plugins\, where a mod manager installs a Customizer skin. Leave the skin there.
  • <Game folder>\Hollow Knight Silksong_Data\Mods\Customizer\, where Customizer keeps its skins. Remove the Customizer plugin first: while it is installed, Stitchwork leaves the skins in this folder alone.

See A1 · switching from Customizer for plugin conflicts. Video skins made for CustomizerCinematic play their cutscenes in place too.

Want to edit a Customizer skin, or keep it as a normal pack? Each Customizer skin card has a Convert button. It copies the skin into a new pack in the global Packs folder, named <skin> (Stitchwork). The skin's own folder does not change. The new pack starts switched off. Switch it on. Switch the Customizer skin off. Click Apply. A large skin shows a progress plate, and a notice lists any files that were left out.

Custom Knight skins from Hollow Knight, in the global Packs folder or under BepInEx\plugins\, show in their own group at the end of the pack list. Stitchwork does not load them as they are. Convert makes <skin> (Knight), a pack for the KnightInSilksong mod, which must be installed. Ask the skin's creator before you share a converted pack.

It loaded — now turn it on

  1. Open the Pack Manager (the Packs panel). Press 1, or click the Packs pull tab at the top edge of the screen. You can also click the status badge (bottom left, not its eye).
  2. Find your pack's card in the list. Did you add the pack while the game ran? Press Rescan in the top row of the panel first, or restart the game.
  3. Your pack is there — but off. New packs start disabled. Click the switch at the right end of the card's bottom bar, then click Apply. Wait for the progress plate at the bottom of the screen. When it's done, your pack is on.

The status badge counts only enabled packs, so a new pack does not change its count.

Your skin is on — go play

That is the end of the player setup. Return to A3 · The Pack Manager when you want to change priority or save profiles. If the skin does not appear, follow A5 · When Something Looks Wrong.

(SHAW.)

Uninstalling

Mod manager: click Uninstall.
Manual: delete the pack's folder from <Game folder>\Packs\ or from BepInEx\plugins\.
Stitchwork's state file may still name the removed pack. This is harmless: Stitchwork removes the entry itself.
No leftover save damage, no vanilla scars.
