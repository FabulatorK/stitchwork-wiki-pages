A1 Getting Started

introplayercreator4 min read
For Stitchwork 0.9.0 · Last edited: 2026-10-19

Foundations · start here.
Install Stitchwork once, then follow the route that fits what you want to do.

Do you want to use skins or make skins?

I just want to use skins

Take the short route: A1 · install Stitchwork, then A2 · install and enable a pack.
Once your skin works, you're done — go play.
Already have Stitchwork? Start at A2.

A3 · The Pack Manager is there when you want to reorder packs or save profiles.
You can skip the rest, which are guides for creators.

I want to make skins (I am a creator)

This route takes more reading and hands-on practice.
You will learn how the game names assets, where replacements belong, and how to test them. You do not need programming knowledge or the Unity Editor, but expect to work through a first edit before tackling a whole skin.

Install Stitchwork in A1, then read A4 · How Stitchwork Works.
From there, choose the graphics, text, audio, or video section to get started. Read the guides your project needs; you do not need to read this wiki cover to cover (unless you want to replace every asset type using all the methods available).

What Stitchwork is

Stitchwork replaces Silksong's art, text, sound, and video with files from packs. It leaves the game's asset files alone. You can enable several packs and choose which wins when they overlap.

Curious about its origins?
A0 · About Stitchwork covers the background story.

Requirements

  • Hollow Knight: Silksong on PC (Windows, macOS, or Linux; Steam or GOG).
  • BepInEx 5, the mod framework. If you already use mods or a mod installer, you likely have it; otherwise see the setup link in Troubleshooting.
  • Enough free disk space for your packs; a large skin can take a few hundred MB or more.

Installing

With a mod manager: install Stitchwork from Thunderstore with Cogfly, Gale, or r2modman, then launch through that manager. Skip the manual steps below.

Installing manually, or updating a manual install
  1. Download the release. Extract all its files into one folder under BepInEx/plugins/, as shown below.
  2. Keep one copy of Stitchwork. When updating, replace the old files rather than leave a second DLL elsewhere.
  3. Launch the game.
…/BepInEx/plugins/StitchworkRoot/Stitchwork.dll
…/BepInEx/plugins/StitchworkRoot/stitchwork.assetbundle
…/BepInEx/plugins/StitchworkRoot/Lang/
…/BepInEx/plugins/StitchworkRoot/LICENSE
…/BepInEx/plugins/StitchworkRoot/LICENSES/

StitchworkRoot is a suggested folder name, chosen to distinguish the plugin from a pack's Stitchwork/ subfolder. Mod managers use their own names; those are fine.

Mods to remove first

These mods replace the same art, sounds or fonts as Stitchwork. Don't run them beside it: remove them from BepInEx/plugins/. Stitchwork does their job.

  • Patchwork. Stitchwork is a fork of Patchwork, and the two can't run together (they fight over sprite loading). If Patchwork.dll is present, Stitchwork goes inert with a main-menu notice. Remove Patchwork.dll to use Stitchwork.
  • Customizer and its variants: Silksong Customizer, MultiCustomizer, CustomizerT2D and CustomizerCinematic. They write the same textures, and the mods collide. Stitchwork loads Customizer skins itself (Installing Packs), and video skins made for CustomizerCinematic play their cutscenes in Stitchwork too. While a Customizer plugin is installed, Stitchwork leaves the skins in Customizer's own folder alone.
  • Font mods: SilksongFontsInject and CustomFontSilksong. They write the same font slots as Stitchwork's font replacement, so the last mod to write a font wins. Stitchwork's log warns about them.
  • Audio mods: CustomAudio, HornetAudioEditor, CustomNeedolin and CustomMusicRandomizer. They replace sounds and music that Stitchwork's audio replacement also replaces.

From the Architect-Silksong editor?
Architect runs fine beside Stitchwork. While Architect's edit mode is on, Stitchwork steps aside: its panels close, and its keys open nothing until you leave edit mode.

First launch

Look for the status badge in the bottom-left corner. Seeing it means Stitchwork is running; click it to open Packs. You can also press 1, or move the mouse to the top edge and click the Packs tab.

First launch asks for one restart. Stitchwork enables incremental GC for smoother performance. It adds one line to the game's boot.config and backs up the original. To undo that setting, set AutoEnableIncrementalGC = false in the config. At the next launch, Stitchwork removes the line, and a notice asks for one more restart to finish.

The Dashboard tab blinks on the first launch: three decisions wait, and two of them matter before your first edit. Press 2 and click each row in the Overview panel.

  • Working folder is where your edits and dumps go: Keep game root (recommended) uses <Game folder>/Stitchwork/, which mod-manager updates never touch.
  • Image editor is the program that every Edit button opens: Keep system default uses your system's app for PNG files, and Browse… selects another program.
  • Target pack can wait: click Not now until you make your first pack in B1 · Starting a Skin Pack.

If you only use skins, keep the defaults of the first two rows.

Choose your next page

  • Use a skin: continue to A2 · Installing Packs. That page ends with your pack enabled and ready to play.
  • Make a skin: continue to A4 · How Stitchwork Works, then choose what to change.
  • No status badge or another problem: use A5 · When Something Looks Wrong.

Opening the tools

You only need Packs to use skins. The tabs from Dashboard to Utilities are the creator tools. To close a tool, click its tab again or press its key again. The controls reference explains moving panels, rolling them out of the way, and key conflicts.

Settings

Press 0, or click the gear tab. Settings › General › Creator tabs hides the creator tabs if you only use packs. For language, folders, rendering, or config-file details, see the Settings reference.

Platform notes
  • Windows, macOS and Linux: all three run Stitchwork natively — folder buttons, Browse dialogs and all. On Linux, the Browse dialogs need zenity or kdialog. Without one, paste the path into the field instead.
