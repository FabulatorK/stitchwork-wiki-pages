Dumping & Full Dump

referencecreator5 min read
For Stitchwork 0.9.0 · Last edited: 2026-10-19

Reference · for creators.
Save the game's own art and text to disk as your reference.
Do one scene at a time, or the whole game at once.

Dumps are templates, not content. Stitchwork never loads from Dumps/ — it's the reference library you copy from when starting an edit. The Pack Doctor — the Check this pack button (the stethoscope) on each pack card — also uses your dumps as ground truth to catch name typos in packs.

The integrity guarantee

Dumps always export the game's original art, even while packs or your own working-folder edits are active. tk2d dumps read the vanilla atlas backup; T2D dumps use the captured pre-swap pixels; text dumps read the game's own strings past any override. You never have to disable your packs to get a clean dump.

The controls (Utilities → Dumping panel)

Open Utilities (7, or the Utilities pull tab). The Dumping panel sits at the right. Its Open folder button opens Dumps/ in your file browser. When the panel is too short for all of its parts, scroll it.

ControlWhat it does
Sprites on scene load (switch, "slower loads")Every scene you enter dumps its sprites to Dumps/Sprites/. Slows scene loads noticeably — leave OFF during normal play.
All game text → Dump all text (button)Exports every text sheet in every language to Dumps/Text/, once, immediately. The game's language flips while it runs, then comes back. At the end, a message shows Text dumped with the counts of languages, sheets and entries, and the time. If a file write fails, the message shows Text dump stopped and the reason.
Full dump (button, "~20 min")Walks every scene in the game, dumping as it goes. The button stays off until Sprites on scene load is on and a game is in progress. The first click arms it and it reads Click to start; click again to start. Returns you to the main menu when done — your save file is never written.
Convert sheets (button)Splits loaded whole-sheet replacements into individual sprite PNGs under Converted/ — with Only sprites that differ from vanilla on, just the frames the sheet altered. The porting exit ramp (B3).

Convert sheets writes a fresh set each time. If Converted/ already has files, a dialog asks what to do with them:

  • Back up, then convert moves the current files to Converted.backup-<date>/ beside it. Nothing is lost.
  • Replace without a backup deletes the current files.

Per-sprite and per-atlas dumping also lives where you browse: in Graphics → Animation, the Edit (new from vanilla) and Ready N sprites for edit buttons; in Graphics → T2D Textures, the Dump row with Atlas, All sprites and Sprite (B2).

Full dump, what to expect

  • Start it from a game in progress. Load a save, then start the dump from the world. At the main menu the button stays off, and the line under it says "Load a save first: the full dump walks the world from a game in progress." When the dump cannot start, a press of FullDumpKey shows the same reason at once, in a Full dump not started message.
  • A progress plate appears at the bottom center: Full dump, the SCENE counter, the current scene with its collection count, and the elapsed minutes. Scenes flash by as the traversal walks the game. A full run is many minutes (the panel says about 20) and several gigabytes of PNGs.
  • The pull tabs hide while the dump runs, and the game's own controls are off. Every Stitchwork panel closes, and Stitchwork's keys open nothing. A press of one shows "The full dump is running. Hold Bksp to cancel it, or wait for it to end."
  • When the run ends, its result stays on the plate for 20 seconds.
  • When it finishes, you're returned to the main menu — without saving. That's deliberate: it guarantees your save file is untouched no matter what the traversal visited. Hit Continue and play on.
  • Any save is safe. Full dump never writes your save file. The dump visits every room, and a room can change your save's progress when you enter it. From the start of the dump to the main menu, Stitchwork blocks every save, autosave, achievement and menu style unlock. A copy of a 100%-complete save is still the nicest one to run it on — the more the world has opened up, the more of it there is to dump — but that's about coverage, not safety.
  • Changed your mind? Hold Backspace for about a second to cancel (FullDumpCancelKey in the config). The plate says "Hold Bksp to cancel · progress is saved", and a held key sweeps red across it. What was dumped so far stays on disk.
  • A new run continues where the last one stopped. It skips the scenes that earlier runs completed (the list is Dumps/.fulldump-progress.txt). When every scene is done, the next run starts fresh.
  • The full-dump key (FullDumpKey, unbound by default) starts a full dump too. Hold it for 1.5 seconds: the hold is its confirm step, so a tap does nothing. While you hold it, the plate shows Full dump, the text "Your session ends here; the dump stops at the main menu", and a fill that grows while you hold. With Sprites on scene load off, a press shows the reason at once. To bind this key or to change the cancel key, open Settings (key 0, or the gear tab at the right end of the pull tabs). The two keys are under Keys: Full dump and Cancel a dump.

Where files land

<Game folder>/Stitchwork/
  Dumps/
    Sprites/{Collection}/{Material}/{Sprite}.png   ← tk2d frames
    Sprites/T2D/{AtlasName}/{Sprite}.png           ← T2D atlas sprites
    Sprites/T2D/_standalone/{Texture}.png          ← textures with no sprite wrapper
    Spritesheets/T2D/{Name}.png                    ← full T2D atlases
    Text/{Sheet}/{LANG}.yml                        ← every string, every language

The dump tree deliberately mirrors the working tree — the two are sibling folders with identical relative paths. Copy a file from Dumps/Sprites/… to Sprites/… in your working folder (or from Dumps/Spritesheets/… to Spritesheets/…; paths reference). Keep the path after the first folder the same, and the file loads. Don't ship Dumps/ inside a pack — the Pack Doctor flags it as debris.

One frame in all three places: the dump, your working folder, and your pack. Each path starts in the game folder. The part from Sprites/ on is the same:

               Stitchwork/Dumps/Sprites/Knight/atlas2/idle0000.png
                     Stitchwork/Sprites/Knight/atlas2/idle0000.png
Packs/my-hornet-skin/Stitchwork/Sprites/Knight/atlas2/idle0000.png
